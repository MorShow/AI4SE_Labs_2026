# Repository Instructions

## Language

- Communicate with the student in their language.
- Write all new assignment deliverables in English, including reports, documentation, code comments, diagram labels, captions, and demonstration outputs intended for assessment.
- Preserve original assignment statements and existing materials unless a change is requested.
- When preparing conversation evidence for assessment, use an English demonstration exchange or clearly label an English translation. Never present a translation or reconstructed example as a verbatim transcript.

## Reports

- Always write short reports in Markdown and save assignment reports as `Report.md` in the corresponding `solutions/Task_j/` directory.
- Summarize completed work in bullet points, using one or two sentences per bullet.
- When concepts or solution methods need explanation, add a separate numbered list.
